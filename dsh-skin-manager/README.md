# 皮肤管理器 1.2.0 · 能碳章鱼与格创东智

在原有默认、黑神话·悟空、能碳章鱼皮肤之外，增加「格创东智」内置皮肤。两套品牌互相切换时，先撤销旧品牌，再启用新品牌；升级保留原有皮肤选择。

## 格创东智效果

- 主色取自用户 2026 标识原图：深蓝 `#292DCD`，辅助亮蓝 `#0396FD`；浅蓝侧栏和浅色内容区，白色输入卡片。
- 产品名 **Gtrontec Harness（格创东智）**，侧栏、欢迎区和标签图标使用原标识的 G 图形，欢迎语为「欢迎使用能碳大脑」。
- 欢迎页预览标记与首次产品内测声明仅在品牌皮肤启用时隐藏，安全和模型配置流程不变。
- 中英文原始 PNG（图片）打包于 `assets/gtrontec/`；原图字节不变。标签图标用自包含 SVG（矢量容器）视窗显示中文组合标识左下角的 G 图形，不重绘标识。
- 右下角中文组合标识作为背景，可见度为桌面 4.5%、窄屏 3.5%，不覆盖正文，不影响点击和弹窗。

## 能碳章鱼效果

- 主色取自用户蓝色标识原图：`#0E1ADF`，浅蓝侧栏、浅色内容区、白色卡片与输入区。
- 品牌名称为 **OCTACARBON Harness（能碳大脑）**，侧栏展开、收起、欢迎页以及浏览器标签图标使用能碳章鱼标识。
- 欢迎语为「欢迎使用能碳大脑」，隐藏欢迎页“预览版”和首次启动的产品内测声明。
- 右下角品牌底纹为会话区域背景，可见度 4.5%，窄屏降至 3.5%；无覆盖层、不截获点击、不改变弹窗层级。
- 原始 PNG（图片）打包在 `assets/octacarbon/`，通过插件同源固定资源路由提供。无需联网下载图片。

## 安装与使用

这是一份**完整皮肤管理器升级包**，不是单独的皮肤数据文件。请同时更新宿主端和浏览器端，不能只替换浏览器脚本。

使用宿主提供的插件命令安装：

```powershell
dsh plugin --profile web add ./dsh-skin-manager-1.2.0.tgz
```

其中 `dsh` 是宿主命令，`web` 是网页运行配置。安装后重启宿主并刷新浏览器，进入 **我的插件 → 皮肤 → 格创东智 → 使用**，也可选择能碳章鱼；没有「我的插件」时进入 **设置 → 皮肤**。升级保留原有皮肤选择，不会自动切换已有用户的皮肤。已通过共享目录安装的环境，应备份后在原位置更新完整包，保留原配置，避免重复登记。

若该命令未加入环境变量，请用本机宿主启动器提供的命令入口。不要重复安装另一个同名皮肤管理器实例。

## 兼容性与实现边界

- 已核对宿主 `0.1.0-rc.8`（候选版本 8）的品牌插槽协议；未改动宿主源码。
- 品牌插槽采用 `priority: -1000`（优先级覆盖），关闭皮肤后撤销，恢复原品牌。产品内测声明仅在该皮肤生效期间隐藏；模型配置、访问权限和安全确认流程不变。
- 宿主尚无欢迎文字、浏览器标题的专用插槽，因此只针对已核对的欢迎标题节点和标签页产品后缀做可撤销适配。宿主升级后应重新验证这两处。
- 不修改用户消息、模型输出、代码、文件名、真实模型/服务商名称和技术标识；因此模型配置里仍按事实展示服务商名称。插件包名、接口地址和皮肤格式标识维持兼容。
- `.dshskin`（皮肤数据文件）规范维持版本 1。它只能表达颜色、样式和背景，**不能单独完成品牌插槽替换**；本品牌皮肤通过完整插件安装。
- 原有导入、切换、卸载和弹窗自适应仍保留。视频皮肤兼容读取导入文件的 `value`（资源值）。

## 资源与开发文件

| 文件 | 用途 |
|---|---|
| `lib/octacarbon.js` | 内置能碳章鱼皮肤与颜色令牌 |
| `lib/gtrontec.js` | 内置格创东智皮肤与颜色令牌 |
| `assets/gtrontec/` | 格创东智两张原始标识、标签图标与品牌样式 |
| `assets/octacarbon/theme.css` | 浅蓝外观、底纹与窄屏样式 |
| `assets/octacarbon/logo-en.png` | 用户原始蓝色英文标识，首个字母为章鱼图形 |
| `assets/octacarbon/logo-zh.png` | 用户原始蓝色中文标识 |
| `assets/octacarbon/logo-combined.png` | 用户原始蓝色中文在上、英文在下组合标识 |
| `assets/octacarbon/favicon.svg` | 原英文 PNG 封装的自包含标签图标；通过视窗只展示章鱼图形，未重绘原图 |
| `tests/octacarbon.test.mjs` | 两套品牌的格式、资源、启停、恢复、内容保护、对比度与生命周期测试 |

开发测试需要 Node.js 24（运行时）以及宿主开发目录中的 React（界面库）、jsdom（页面测试库）。`HARNESS_ROOT` 环境变量可指向宿主根 `package.json` 文件以改变依赖位置。运行 `npm test`（测试命令）；打包使用 `npm pack`（生成安装包）。源码包保留测试，安装包仅含运行文件与文档。

## 数据与回退

皮肤选择与导入清单位于插件实际安装目录同级的 `skins/`（皮肤数据目录）。共享目录安装时通常为 `$DSH_HOME/profiles/node_modules/skins/`；保持该目录不变，升级不会清空它。

只需恢复外观时，在皮肤列表选择「默认皮肤」或「能碳章鱼」。需回退程序版本时，先切到旧版本支持的皮肤，恢复备份的 `1.1.0` 完整插件并重启宿主、刷新浏览器；保留皮肤数据目录。
