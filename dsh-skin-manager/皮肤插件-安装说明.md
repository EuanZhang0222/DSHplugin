# 皮肤插件 —— 安装与使用说明

> **1.2.0 更新**：新增「格创东智」，保留「能碳章鱼」等原有皮肤，完整安装包为 `dsh-skin-manager-1.2.0.tgz`。请以 [README.md](README.md) 的升级、品牌边界和回退说明为准。安装后在「我的插件 → 皮肤」（未安装聚合插件时为「设置 → 皮肤」）选择「格创东智」。必须同时更新宿主与浏览器文件并重启/刷新，不能只导入皮肤数据文件；升级不会自动改变当前选择。

本插件为 DeepSeek Harness（DSH）增加「皮肤」能力：在 **设置页左侧** 新增一个
「皮肤」切换入口，内置「默认皮肤」「黑神话·悟空皮肤」「能碳章鱼」「格创东智」，并支持**导入皮肤文件、
安装新皮肤、一键切换、卸载**。

- 🎨 内置皮肤：默认皮肤（DSH 原生外观）、黑神话·悟空（黑金配色 + 毛玻璃金边 + 悟空官网视频底纹）
- 🔁 一键切换：点「使用」立即生效，刷新后保持
- ➕ 新增皮肤：导入 `.dshskin` 皮肤文件实现安装
- ✅ 严格校验：按《皮肤文件格式规范》逐字段校验，不合规文件被拒绝并给出中文原因
- 🗑️ 卸载：已导入皮肤可一键卸载
- ↔️ 自适应布局：皮肤页面跟随「我的插件」弹窗宽高铺满可用区域；宽弹窗自动多列，窄弹窗自动单列并换行

> 本质是一个 DSH **双面插件**：host 半部负责皮肤目录、校验、存储与 HTTP API；client 半部负责设置页 UI、主题令牌覆盖、样式与背景注入。不修改 DSH 源码。

## 一、交付物

| 文件 | 说明 |
|---|---|
| `install.ps1` / `install.sh` | 源码安装脚本（insert 方式，会清除旧冲突插件，使用前备份；安装后重启） |
| `package.json`、`lib/`、`assets/` | 插件本体源码（install 脚本复制它们到 DSH） |
| `dsh-skin-manager-1.2.0.tgz` | 标准 npm tarball，供 `dsh plugin add` 方式安装 |
| `皮肤文件格式规范.md` | 可导入皮肤文件（`.dshskin`）的格式与要求 |
| `examples/` | 三个示例皮肤文件，可直接导入体验 |
| 本说明文档 | 安装与使用指引 |

---

## 二、前置条件

- 已安装并可运行 DeepSeek Harness（Web 版，即 `dsh web` / `--profile web` 启动的界面）。
- 仅「方式 B（bundle 命令）」需要本机 `pnpm` 可用；「方式 A（安装脚本）」不需要。

> 说明：插件的 HTTP 接口与资源路由依赖 web 应用层（`webServer` 服务），因此请安装到
> **web profile**（即你平时用浏览器打开的 DSH），而不是 headless/base profile。

---

## 三、安装步骤

### 方式 A：源码安装脚本（insert 方式，安装后重启）

正式升级建议先备份并在原安装位置更新完整包。下述旧脚本会清除冲突插件；有定制配置时不要未经核对直接运行。

1. 把整个 `dsh-skin-manager/` 文件夹复制到目标电脑（脚本与源码需在同一目录）。

2. - **Windows**：右键 `install.ps1` → **使用 PowerShell 运行**（被拦截时先执行
     `powershell -ExecutionPolicy Bypass -File .\install.ps1`）。
   - **macOS / Linux**：

     ```bash
     cd dsh-skin-manager
     chmod +x install.sh
     ./install.sh
     ```

3. 脚本会自动完成三件事：
   - **清除旧的常驻皮肤插件**（`dsh-skin-deepseek` / `dsh-skin-wukong` 的目录与 `cordis.patch.yml` 条目）；
   - 复制插件到 `$DSH_HOME/profiles/node_modules/dsh-skin-manager/`；
   - 在 `cordis.patch.yml` 登记插件行（`inject: [webServer]`）。

4. **生效**：
   - 已核对的候选版本 8 网页宿主禁用插件热重载，必须同时更新全部文件并重启 `dsh web`，再刷新浏览器。
   - 重启前确认没有运行任务；刷新前保存旧页面未完成的内容。不要只复制浏览器脚本。

### 方式 B：标准插件命令（bundle 方式，需重启）

1. 打开终端，执行：

   ```bash
   dsh plugin --profile web add ./dsh-skin-manager-1.2.0.tgz
   ```

   或绝对路径：

   ```bash
   dsh plugin --profile web add "C:/path/to/dsh-skin-manager-1.2.0.tgz"
   ```

   > 若 `dsh` 不在 PATH 中：`node <DSH安装目录>/apps/cli/lib/bin.js plugin --profile web add ./dsh-skin-manager-1.2.0.tgz`

2. 安装后插件会写入 web profile 的 bundle 清单。**重启 DSH**（bundle 清单变化需重启才生效）。

### 方式 C：图形界面（若你的 DSH 提供插件管理页）

部分 DSH 版本在「设置 → 插件」中提供插件安装入口，可上传 `.tgz` 安装。安装后同样需要重启 DSH。

## 四、验证安装是否成功

打开 **设置** 面板，确认左侧导航包含：

```
通用设置 · 模型 · 插件 · Agent 预设 · 皮肤
```

进入后应能看到「默认皮肤」「黑神话·悟空」「能碳章鱼」「格创东智」四项；还应核对新品牌图片正常、切换生效，不能只凭出现菜单认定升级成功。

命令行可进一步验证（可选）：

```bash
# 皮肤目录接口（host 半部已加载时返回 200 + 皮肤列表）
curl -s http://127.0.0.1:3080/api/dsh-skins/state
```

## 五、使用方法

1. 打开 DSH → 左下角 **设置** → 左侧点选 **「皮肤」**。

2. **切换皮肤**：在皮肤列表点某张皮肤右侧的「使用」，界面立即换肤；当前生效的皮肤
   标「使用中」。

3. **新增皮肤（导入）**：页面底部「新增皮肤」→「选择皮肤文件并安装」→ 选中一个
   `.dshskin` 文件。合法则进入皮肤列表，不合法则显示具体哪一项不合规。

4. **卸载皮肤**：已导入的皮肤显示「卸载」按钮（点两次确认）；内置皮肤不可卸载。

> 皮肤文件的格式与要求见《皮肤文件格式规范.md》；`examples/` 里有三个现成的
> 皮肤文件，可直接拿来导入体验。

---

## 六、数据存储位置

- **已导入皮肤 + 当前选中皮肤**：持久化在 `$DSH_HOME/profiles/node_modules/skins/（共享目录安装；实际位置为插件实际安装目录同级的 skins/）`
  （`index.json` 记录选择与已安装清单，每个皮肤一个子目录存放 `manifest.json`）。
- **内置皮肤**（默认、黑神话·悟空、能碳章鱼、格创东智）：随插件打包，无需存储。

---

## 七、卸载

- 方式 A 安装的：删除 `$DSH_HOME/profiles/node_modules/dsh-skin-manager/`，并从
  `$DSH_HOME/profiles/web/cordis.patch.yml` 移除其 `insert` 条目。
- 方式 B 安装的：

  ```bash
  dsh plugin --profile web remove dsh-skin-manager
  ```

然后刷新浏览器（或重启 DSH）。已导入的皮肤数据保留在 `$DSH_HOME/profiles/node_modules/skins/（共享目录安装；实际位置为插件实际安装目录同级的 skins/）`，
如需彻底清除可手动删除该目录。

## 八、常见问题

- **Q：安装后设置页没有「皮肤」？**
  A：先完整更新插件并重启宿主，再刷新浏览器；已核对的网页宿主不支持插件热重载。
  并确认安装到的是 web profile 而不是 base/headless profile。

- **Q：导入皮肤文件提示「id 已存在」？**
  A：皮肤 `id` 不能与内置皮肤（`default`、`wukong`、`octacarbon`、`gtrontec`）或已安装皮肤重复。`examples/wukong.dshskin`
  的 id 是 `wukong`，与内置的黑神话皮肤同 id，因此在已装本插件的环境里导入它会被
  拒（这正是校验规则之一）；把文件里 `"id"` 改成别的（如 `"wukong-copy"`）即可导入。

- **Q：导入皮肤文件提示「不是合法的 JSON」？**
  A：皮肤文件必须是 UTF-8 编码的 JSON 文本；确认没被编辑器改成 BOM 或其它编码。

- **Q：视频背景为什么不显示 / 一直加载？**
  A：视频背景需为 `data:video/...` base64 内嵌或可访问的外部 URL；确认地址可访问，
  浏览器也需允许自动播放（DSH 界面内通常已静音自动播放）。

- **Q：和旧皮肤插件（dsh-skin-deepseek / dsh-skin-wukong）冲突？**
  A：这些旧插件是「常驻覆盖」式，会与本插件的切换叠加冲突。**方式 A 的安装脚本会
  自动清除它们**；方式 B 请先手动卸载旧插件，再安装本插件。
