# DSH 皮肤文件格式规范（.dshskin）

本文档定义 **可导入皮肤文件** 的格式与要求，即「什么样的文件能被皮肤管理器接受并安装」。

一个皮肤文件就是一个 **UTF-8 编码的 JSON 文本文件**，建议扩展名为 `.dshskin`（也接受 `.json`）。安装时，皮肤管理器会逐字段校验；**任何一条不满足都会拒绝导入并给出中文错误提示**。

---

## 1. 顶层结构

皮肤文件顶层是一个 JSON 对象，字段如下：

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| `schema` | string | ✅ | 固定为 `"dsh-skin"` |
| `schemaVersion` | number | ✅ | 固定为 `1` |
| `id` | string | ✅ | 皮肤唯一标识，见 §2 |
| `name` | string | ✅ | 显示名称，1~64 字符 |
| `version` | string | ✅ | 语义化版本，形如 `1.0.0` |
| `colorScheme` | string | ✅ | 视觉基调，`"light"` 或 `"dark"` |
| `author` | string | 否 | 作者，≤64 字符 |
| `description` | string | 否 | 描述，≤512 字符 |
| `tokens` | object | 否 | 主题颜色令牌覆盖，见 §3 |
| `css` | string | 否 | 自定义样式，见 §4 |
| `background` | object | 否 | 背景配置，见 §5 |

---

## 2. `id` 规则

- 由小写字母或数字开头；
- 后续只能是小写字母、数字或连字符 `-`；
- 总长度 1~64；
- 正则：`^[a-z0-9][a-z0-9-]{0,63}$`；
- **不得与内置皮肤（`default`、`wukong`、`octacarbon`、`gtrontec`）或已安装皮肤重复**。

✅ 合法：`ocean-blue`、`my-skin`、`cute2`
❌ 非法：`Ocean-Blue`（大写）、`-bad`（连字符开头）、`皮肤1`（中文）、`a` 之后超过 64 字符

---

## 3. `tokens`（主题颜色令牌）

`tokens` 是一个对象，键为 CSS 自定义属性名，值为 **CSS 颜色**。

- **键**：必须以 `--` 开头（如 `--dsw-alias-brand-primary`、`--dsw-specific-sidebar-fill`）。
- **值**：只能是 CSS 颜色，接受以下形式：
  - 十六进制：`#0b0a08`、`#d4b06a`
  - `rgb()` / `rgba()`：`rgba(212, 176, 106, 0.5)`
  - `hsl()` / `hsla()`：`hsl(220, 60%, 50%)`
  - 颜色关键字：`transparent`、`white` 等
- **安全限制**：值中不允许出现 `;`、`{`、`}`、`url(`。令牌只能是纯颜色，不能借此注入多值或引用外部资源。

> 常用令牌参考（DSH 内置主题变量）：`--dsw-alias-bg-base`、`--dsw-alias-bg-layer-1`、`--dsw-alias-brand-primary`、`--dsw-alias-label-primary`、`--dsw-alias-button-primary-fill`、`--dsw-specific-sidebar-fill` 等。令牌不要求写全，缺省的部分沿用当前主题。

---

## 4. `css`（自定义样式）

- 必须是字符串，长度 ≤ 64KB；
- 会被注入为一个 `<style>` 标签，仅在启用该皮肤时生效；
- **禁止**出现以下内容（会直接拒绝导入）：
  - `</style`（破坏样式标签结构）
  - `expression(`（旧式 CSS 表达式）
  - `javascript:`
  - `@import`
  - `-moz-binding`
  - `behavior:`

即：样式只能作用于界面本身，**不允许引入外部样式或任何脚本行为**。

---

## 5. `background`（背景）

`background` 是一个对象：

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| `type` | string | ✅ | `color` / `gradient` / `image` / `url` / `video` |
| `value` | string | ✅ | 与 `type` 匹配的取值 |
| `opacity` | number | 否 | 不透明度 0~1，默认 0.3 |
| `brightness` | number | 否 | 仅 `video` 可用：视频亮度滤镜，正数（如 2 表示提亮一倍） |

`type` 与 `value` 的对应关系：

| type | value 要求 | 示例 |
|------|-----------|------|
| `color` | CSS 颜色 | `"#0a0e1a"` |
| `gradient` | `linear/radial/conic-gradient(...)` | `"linear-gradient(160deg, #0a0e1a, #12203f)"` |
| `image` | `data:image/...` 内嵌图片 | `"data:image/png;base64,iVBOR..."` |
| `url` | `http(s)://` 图片地址 | `"https://example.com/bg.jpg"` |
| `video` | `data:video/...` 内嵌视频，或 `http(s)://` 视频地址 | `"data:video/mp4;base64,AAAAGG..."` |

> 说明：`video` 背景通过 base64 内嵌（`data:video/...`）或外部 URL 提供。内嵌视频会让皮肤文件变大（一段 1MB 视频约对应 1.3MB 的 JSON），但这是让「含视频皮肤」也能通过文件导入的方式。完整范例见 `examples/wukong.dshskin`。

---

## 6. 完整示例

见 `examples/ocean-blue.dshskin` 与 `examples/rosy-light.dshskin`。最小可用皮肤：

```json
{
  "schema": "dsh-skin",
  "schemaVersion": 1,
  "id": "my-skin",
  "name": "我的皮肤",
  "version": "1.0.0",
  "colorScheme": "dark",
  "tokens": {
    "--dsw-alias-brand-primary": "#4a9fd8"
  }
}
```

---

## 7. 校验规则清单（能否导入的判定）

皮肤管理器按以下顺序校验，**全部通过才安装**：

1. 顶层是 JSON 对象；
2. `schema === "dsh-skin"` 且 `schemaVersion === 1`；
3. `id` 匹配 §2 且不与内置/已安装皮肤冲突；
4. `name` 为 1~64 字符字符串；
5. `version` 匹配 `^\d+\.\d+\.\d+$`；
6. `colorScheme` 为 `"light"` 或 `"dark"`；
7. `tokens`（若提供）：键以 `--` 开头、值为合法 CSS 颜色；
8. `css`（若提供）：字符串、≤64KB、不含 §4 危险片段；
9. `background`（若提供）：`type` 合法、`value` 匹配、`opacity ∈ [0,1]`、`brightness`（若提供）为正数。

任意一条不满足 → 拒绝导入，界面显示具体哪一项不合规。

## 8. 内置品牌皮肤与数据文件的边界

1.1.0 版本增加 `octacarbon`（能碳章鱼），1.2.0 版本新增 `gtrontec`（格创东智）内置皮肤。其颜色与样式遵循本规范，但侧栏/欢迎页标识、品牌名称和标签页图标通过插件代码与宿主品牌插槽实现，不是本格式新增了脚本执行能力。

本次保持 `schemaVersion: 1`（格式版本 1），不接受从皮肤数据文件指定脚本或注册品牌插槽。需要两套完整品牌效果时，请安装皮肤管理器 1.2.0 完整包；不要把纯颜色 `.dshskin` 文件当作完整品牌插件交付。

内置品牌图片位于 `assets/octacarbon/`、`assets/gtrontec/`（资源目录），必须列入安装包；底纹应绘制为会话区域背景，不使用覆盖文字、截获点击或改变弹窗堆叠关系的浮层。正文和白色输入区应保持足够对比度。切换品牌时需撤销旧品牌插槽、标签图标、欢迎语和标题适配，不能同时保留两套品牌覆盖。
